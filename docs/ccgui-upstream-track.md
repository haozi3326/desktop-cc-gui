## 借鉴用法（给工程）

1. `git fetch upstream --tags`
2. 钉基线：产品 tip（例 `12cabcb96`）与上游目标（例 `v1.1.6` / 单 commit）
3. `git log --oneline <产品tip>..<上游目标>` 或对单文件 `git diff <产品tip>..<上游目标> -- path`
4. **禁止** `git merge upstream/main` 整包；只 cherry-pick / 移植经一页纸批准的切片
5. 合入后更新本文件「对照快照」与「已具备 / 增量」表
